# Система управления базой знаний

MVP системы управления базой знаний на Electron с поддержкой Markdown и YAML-фронтметтера.

## Возможности

- Создание, редактирование, удаление и переименование Markdown-файлов
- YAML-фронтметтер с автоматической генерацией метаданных
- Поиск по названию файла
- Тегирование файлов и фильтрация по тегам
- Автосохранение изменений
- Горячие клавиши (Ctrl+S для сохранения)
- Отслеживание изменений в файловой системе

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

или

```bash
npm run dev
```

## Структура файлов

```
my-knowledge-base/
├── knowledge/           # Папка с .md файлами
├── src/
│   ├── main/
│   │   ├── main.js     # Главный процесс Electron
│   │   └── preload.js  # Прелоад скрипт
│   ├── renderer/
│   │   ├── index.html  # Интерфейс
│   │   ├── styles.css  # Стили
│   │   └── renderer.js # Логика рендерера
│   └── common/
│       ├── fileManager.js   # Работа с файлами
│       ├── parser.js        # Парсинг YAML/Markdown
│       ├── searchIndex.js   # Поисковый индекс (Lunr)
│       └── watcher.js       # Отслеживание файлов (Chokidar)
├── package.json
└── README.md
```

## Использование

1. **Создание файла**: Нажмите "+ Новый файл" и введите название
2. **Редактирование**: Кликните на файл в списке, отредактируйте содержимое
3. **Сохранение**: Нажмите кнопку "Сохранить" или Ctrl+S
4. **Поиск**: Введите текст в поле поиска для фильтрации списка
5. **Теги**: Кликните на тег для фильтрации файлов
6. **Переименование/удаление**: Используйте соответствующие кнопки

## Формат файлов

Файлы должны содержать YAML-фронтметтер:

```yaml
---
title: "Название статьи"
date: 2025-04-15
tags: ["тег1", "тег2"]
---

Содержимое статьи в Markdown...
```

## Зависимости

- Electron
- gray-matter (парсинг YAML)
- chokidar (файловый вотчер)
- lunr (поисковый движок)
- date-fns
